# Operation: Legacy

A story-driven 2D military action game built with Godot.

## About

Operation: Legacy is a pixel art action game focused on teamwork, character development, and tactical combat. The story follows Bravo Unit as they navigate a world shaped by political conflict, difficult decisions, and personal sacrifice.

## Features

- Story-driven campaign
- Pixel art graphics
- Run and Gun combat
- Character progression

🚧 This project is currently in active development.
